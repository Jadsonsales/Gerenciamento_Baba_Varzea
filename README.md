# Baba de Várzea 🏆

Sistema completo de gestão de baba em Angular 19.

## Como rodar

```bash
```cmd
npm install
npm start
```

Acesse: http://localhost:4200

## Login
- Email: admin@babamanager.com

## Páginas
- **Dashboard** — visão geral do baba
- **Cansado(uma gíria de Baba)s** — cadastro e gestão de jogadores
- **Mensalidades** — controle de mensalidades
- **Sorteio de cansados** — sorteio inteligente de times
- **Seu Baba** — personalização do baba
- **Aviso** — avisos e comunicados
- **Configurações** — conta e preferências
